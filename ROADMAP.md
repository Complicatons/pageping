# Roadmap

Where PagePing is, and what has to happen before anyone outside the project can use it. Last updated 6 November 2026.

PagePing is a local development beta. It is not publicly launched and nothing is for sale. Stages below happen in order, and each only starts when the one before it is finished and checked. There are no promised dates.

## Done: the product, running locally

- [x] Page monitoring with HTTP and full-browser checks
- [x] Section selection with a preview of what PagePing can see
- [x] Text, number, price and stock rules, with a preview before saving
- [x] Before-and-after evidence, history and number tracking
- [x] Watch Collections: one product compared across several pages you choose
- [x] Selection repair you confirm yourself
- [x] Rule replay against saved history
- [x] Temporary speed boosts
- [x] Email alert preferences, grouped changes, failure and recovery notices
- [x] Accounts, verification, password reset, shared team workspaces with roles
- [x] Data import and export
- [x] New brand, logo and redesigned website and app (6 November 2026)
- [x] Automated test suite and browser checks of the main journeys

## Next: a private hosted beta

A small number of invited people using a hosted version, free of charge, with the product set up for them personally.

- [ ] Secure hosting with HTTPS and off-server backups
- [ ] Real email delivery for alerts
- [ ] Respect for robots.txt, a public crawler policy and a way for site owners to opt out
- [ ] Monitoring of the service itself, so missed checks are noticed

## Then: a paid beta for invited customers

- [ ] Plans and prices confirmed
- [ ] Live payments with online cancellation and renewal reminders
- [ ] Terms of service, privacy notice and acceptable-use policy published
- [ ] A public status page
- [ ] Slack and webhook alerts, before any team plan is offered

## After that: public free sign-up

- [ ] Sustained load testing to set fair plan allowances
- [ ] An independent security review
- [ ] Open sign-up for the free plan

## Later ideas, not commitments

- A browser extension for picking page sections
- A Shopify app for shops that want to pair their own products with rival pages
- More alert channels and integrations

This roadmap shows direction, not promises. It will change as the product is tested with real users, and every change will be recorded in the [product updates](CHANGELOG.md).
